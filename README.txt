PawMeet 四章互动展示 · 2026-10-18

页面分组
1. 探索 / 消息
2. 圈子 / 动态详情
3. 多宠身份 / 成长手账 / 日常记录
4. 附近推荐 / 线上活动 / 同城活动

体验方式
点击每页的大号功能按钮，切换手机内的展示界面。
在电脑上，将鼠标放在手机外轻滚滚轮，可吸附到下一章节；手机内部可独立滚动。
手机窄屏采用连续下拉布局。手机下方的放大按钮可放大产品。
探索支持换一位、喜欢和横向滑卡。圈子中的探店照片可打开对应动态。
动态支持点赞、收藏、评论和回复。多宠身份支持切换。日常记录保留记录表单。
推荐和活动可滚动查看，性格测试可进入。成长手账及消息为浏览展示。
所有互动数据保存在本页内存，刷新后重置。不会提交到线上产品。

文件
index.html / studio.css / studio.js：外层展示。
app/*.html：从原产品 DOM 中提取的十个独立界面，没有原 App 启动和路由流程。
app/original.css：保留原产品样式及字体。
app/polish.css：统一界面组件、间距、标签、图标的展示层细化。
app/screen.js：当前体验的有限交互。
app/assets/paw-hand.woff2：按页面文字子集化的“小赖字体”，仅用于外层展示。
FONT-LICENSE.txt：字体的 SIL Open Font License。
字体来源 https://github.com/lxgw/kose-font 。字体随页面打包，无需在线加载。

可直接打开同目录外的 PawMeet-Studio-明亮新版.html 单文件离线版。
网站目录适合静态服务器部署；配套 zip 内包含全部网站资源。

本次修订：探索和圈子直接使用 v0.9.3.11 APK 的 DOM 与样式。探索保留原滑卡模块。
app/apk-*.css / apk-*.js：原界面与仅供展示的内存适配。圈子随机占位图换为已有本地配图。
引导使用浅灰紫手绘文字与箭头，点击界面任意处后消失；切换引导只在第一页出现。
